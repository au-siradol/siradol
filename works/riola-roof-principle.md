## 1. chain ในหน้าตัด (เหนือ → ใต้)

```
ผนัง→shell (ม้วนขึ้นจากพื้น)
  → กระจก 1 (ดิ่ง) → ครีบ 1
  → กระจก 2 (ดิ่ง) → ครีบ 2
  → กระจก 3 (ดิ่ง) → ครีบ 3 (+ ขายื่นลงถึงพื้น)
```

- **ครีบ (scoop)** = เปลือกบางรูปเสี้ยว โคนด้านเหนือหนา ปลายด้านใต้บางเชิดขึ้น
- **กระจก** ตั้งดิ่งเสมอ หย่อนจากปลายครีบตัวก่อน ลงมาหัวโคนครีบตัวถัดไป
- ทั้งชุดไล่ระดับลง เหนือ → ใต้

## 4. ชิ้นส่วนแบ่งเป็น 2 ประเภท ← หัวใจของหลักการ

### แข็ง (rigid) — ครีบ 1 / 2 / 3
- ย่อ **uniform** ด้วย `k = LF·span / L_master`
- **ไม่หมุน ไม่บิด ไม่ยืดด้านเดียว**
- วางโดยให้ **rootBot แตะเส้นกึ่งกลาง rib** ที่ `x = tallFootX + rF·span`

### ยืดได้ (elastic) — ยึดปลาย 2 ข้าง แล้วยืดระหว่างนั้น

**ผนัง→shell**
- ฐาน = `(ผิวนอกขา rib, พื้น)` — อยู่บนพื้นเสมอไม่ว่า rib จะสูงแค่ไหน
- ยอด = `(x ของกระจก 1, WALL_TOP_K × ความสูงยอด rib)`
- ยืดตามแกน ฐาน→ยอด · ความหนาตั้งฉากคูณ `span / SPAN0`

**ขาครีบ 3**
- จุดที่อยู่เลย `fold` ลงไป ยืดจนปลายแตะพื้นพอดี
- **clamp** ห้ามเลยพื้นลงไป

**กระจก 1 / 2 / 3**
- ขอบล่าง = `rootTop` ของครีบตัวนั้น
- ขอบบน = `tip` ของครีบตัวก่อนหน้า · (กระจก 1 = ยอดของ wall→shell)
- → กระจก **คือช่องว่างเอง** จึงเติมพอดีทุก rib profile ไม่มีวันเกิด gap

## 5. เส้นกึ่งกลาง rib (datum)

ครีบทุกตัวเกาะเส้นนี้ ไม่ใช่ผิวนอกหรือผิวใน

1. sample path ของ rib (closed ribbon) แล้วหาจุด x น้อยสุด → แบ่งเป็น outer / inner
2. ที่ x ใด ๆ: `centre(x) = ( y_outer(x) + y_inner(x) ) / 2`
3. จำกัดเฉพาะ **ช่วงหลังคา** ระหว่างเข่า 2 ข้าง (ในไฟล์: `X0 = 258`, `X1 = 584`)
4. เลย `X1` ออกไป → **extrapolate เชิงเส้น** ด้วยความชันช่วงท้าย
   (จำเป็น เพราะโคนครีบ 3 อยู่ที่ x ≈ 600 ซึ่งเลยเข่าผนังสั้นไปแล้ว)

## 6. elastic map (สูตร)

map `srcA→dstA`, `srcB→dstB` โดยยืดตามแกน แต่คุมความหนาด้วย `perpK`

```js
function elastic(srcA, srcB, dstA, dstB, perpK) {
  const sv = {x: srcB.x-srcA.x, y: srcB.y-srcA.y}, sl = Math.hypot(sv.x, sv.y) || 1;
  const su = {x: sv.x/sl, y: sv.y/sl}, sn = {x: -su.y, y: su.x};
  const dv = {x: dstB.x-dstA.x, y: dstB.y-dstA.y}, dl = Math.hypot(dv.x, dv.y) || 1;
  const du = {x: dv.x/dl, y: dv.y/dl}, dn = {x: -du.y, y: du.x};
  const kA = dl / sl;
  return p => {
    const d = {x: p.x-srcA.x, y: p.y-srcA.y};
    const a = d.x*su.x + d.y*su.y;      // ตามแกน
    const b = d.x*sn.x + d.y*sn.y;      // ตั้งฉาก
    return { x: dstA.x + du.x*a*kA + dn.x*b*perpK,
             y: dstA.y + du.y*a*kA + dn.y*b*perpK };
  };
}
```

## 8. ความผิดพลาดที่เคยทำ (อย่าทำซ้ำ)

1. **เอา scoop 1 มาย่อใช้ทั้ง 3 ตัว** → ขาของครีบ 3 หายไป · ต้องใช้ path ของแต่ละตัว
2. **สร้าง arch จำลองมาเป็น datum** แทนที่จะใช้ path rib จริง → ทุกอย่างเลื่อนตาม
3. **anchor ตีน wall = ตีน rib** → wall มุดเข้าเนื้อ rib · ที่ถูกคือผิวใน wall แนบผิวนอกขา rib
4. **คำนวณยอดกระจก 1 แยกจาก wall** → ปลายไม่แตะกัน · ที่ถูกคือยอดกระจก 1 = ปลาย wall
5. **วาง wall แบบ rigid** → ฐานลอย/จมเมื่อ rib เปลี่ยน · ต้องเป็น elastic ฐานพินที่พื้น
6. **ยืดขาครีบ 3 โดยไม่ clamp** → ทะลุพื้น
7. **ตั้งความสูงกระจกเป็นค่าคงที่** `c·L` → เกิด gap เมื่อ rib เปลี่ยน · ต้องนิยามด้วยปลาย 2 ข้าง
8. **สร้างครีบเป็นรูปทรงพาราเมตริกที่คิดเอง** (ทางลาดเรียบ / sawtooth) → ไม่เหมือน Riola เลย

## 11. การตรวจโครงสร้าง (เพิ่ม 2026-09-03)

ตอบคำถาม "จะกันไม่ให้ลากสไลเดอร์แล้วได้รูปทรงที่ขัดหลักการถ่ายแรงได้ไหม"
→ **ไม่ล็อกสไลเดอร์** (การได้ลากจนพังแล้วเห็นว่าทำไม คือคุณค่าของ study)
แต่**เพิ่มการตรวจที่บอกว่าผิดหลักตรงไหน** แสดงเป็นบรรทัดที่ 2 ใต้ SAFE/FAILURE

### ก. น้ำหนักตัวเองตามวัสดุ — `ribSelfWeight()`
| | ตัวอย่าง | ผล |
|---|---|---|
| RC `0.6 × 2.2` | `b·h·24` = **31.7 kN/m** | หนักกว่าเปลือกที่มันแบก (22.7) |
| เหล็ก 600×190 | `A·78.5` = **3.1 kN/m** | แทบไม่มีผล |

→ เลือกวัสดุมีผลต่อ **Mu** ไม่ใช่แค่ **Mn**

### ข. เส้นแรง (thrust line) — `thrustCheck()`
ใต้น้ำหนักสม่ำเสมอ มีรูปเดียวที่รับเป็นแรงอัดล้วน = **funicular (พาราโบลา)**
สร้างพาราโบลาบนคอร์ดระหว่างเข่า 2 ข้าง **ให้มี rise เท่ากับ rib** → ส่วนต่างคือความผิดรูปล้วนๆ
`e` = ระยะเยื้องสูงสุด · รายงาน **`e / (h/2)`** — เกิน 1 คือเส้นแรงหลุดนอกหน้าตัด เกิดแรงดึงที่หลังโค้ง

ผลที่เห็นเวลาลาก (span 24, h 2.2):
| | e/(h/2) |
|---|---|
| crown 7 (แบน) | 0.56 — อยู่ในหน้าตัด |
| default crown 14 | 1.15 |
| crown 26 (ชันมาก) | 4.94 |
| ยอดเยื้อง crownX 22 | 3.16 |
| section ตื้น h 0.4 | 6.30 |

### ค. Lateral-torsional buckling ของเหล็ก — `ltbFactor()`
`Mb = χLT · Zpl · Fy` โดย `χLT = 1/(1+(λ/90)²)`, `λ = spacing / ry`, `ry ≈ 0.25·B`
คอนกรีตไม่มีปัญหานี้ → **สไลเดอร์ Spacing กัดเหล็กแรงกว่าคอนกรีตมาก**

| spacing | χLT | Mn เหล็ก 600×190 | ผล |
|---|---|---|---|
| 3.0 m | 0.67 | 1351 | SAFE (Mu 519) |
| 5.5 m | 0.38 | 759 | FAILURE (Mu 864) |
| 9.0 m | 0.25 | 504 | FAILURE (Mu 1347) |

### ง. อัตราส่วนรูปทรง — `formFlags()`
เตือนเมื่อออกนอกช่วงที่ portal frame ใช้จริง
- `rise/span < 1/12` — แบนเกิน
- ตำแหน่งยอด นอก `0.15–0.70` ของ span — กลายเป็นคานยื่นมีค้ำ
- ความสูงเสา `> 0.8 × span` — sway ครอง
- `haunch < 3 %` ของ span — เข่าคม stress concentration

พร้อมบอกสัดส่วนความลึกเทียบการใช้จริง: RC ≈ 1:20–1:25 · เหล็ก ≈ 1:35–1:45

### จ. แก้ค่า capacity ของ RC
`b·h²·500` → **`b·h²·1200`** — ค่าเดิมเทียบเท่าเหล็กเสริมแค่ ~0.15 % ซึ่งต่ำเกินจริง
ค่าใหม่ ≈ `0.9·As·fy·0.9h` ที่ ρ ≈ 0.4 % (คานเสริมเหล็กปกติ)

## 12. ขอบเขตของ rib profile (แก้ 2026-09-03 รอบสอง)

### ก. รัศมี fillet ถูกล้อมทั้งสองข้าง
| ขอบ | ค่า | เหตุผล |
|---|---|---|
| ต่ำสุด | `0.9 × ความลึก section` | offset curve พับทับตัวเองเมื่อรัศมีความโค้ง < ระยะ offset (`h/2`) · และดัดชิ้นส่วนลึกให้โค้งแคบกว่าตัวเองไม่ได้จริง |
| สูงสุด | **จากมุมจริงที่มุม** | fillet รัศมี `r` ที่มุมภายใน θ กินความยาว `d = r / tan(θ/2)` จากช่วงข้างเคียง · fillet สองตัวที่ใช้ช่วงร่วมกันต้องไม่กินเกินช่วงนั้น |

**บทเรียน:** เคยตั้งขอบบนมั่วเป็น `0.4 × ชิ้นส่วนสั้นสุด` → บีบเกินจริง **2–5 เท่า**
เพราะมุมเข่าที่นี่เป็นมุมป้าน (105–170°) `tan(θ/2)` ใหญ่ ความยาว tangent จึงสั้น ใช้รัศมีใหญ่ได้สบาย

| กรณี | ขอบเขตจริง | ค่ามั่วเดิม |
|---|---|---|
| default | 4.99 | 1.88 |
| span 36 | 7.91 | 2.40 |
| wallLo 2 | 3.87 | 0.80 |

`ribLimits()` คืน `{ rHaunchMax, rCrownMax, maxDepth }` — **haunch กับ crown คิดเพดานแยกกัน**
(มุมยอดกับมุมเข่าต่างกันมาก เช่น 51° กับ 170°)

### ข. ความลึก section ถูกจำกัดโดยเฟรม
`maxDepth = 0.5 × min(rHaunchMax, rCrownMax)`

**บทเรียนสำคัญ:** เคยตั้ง `maxDepth = rMax / 0.9` ซึ่งทำให้ `MIN_BEND(maxDepth) = rMax` **พอดีเป๊ะ**
→ ขอบล่างกับขอบบนชนกัน ช่วงเป็นศูนย์ → **สไลเดอร์ Haunch/Crown ค้างไม่ขยับเลย**
ต้องเผื่อช่องว่างเสมอ · ค่า 0.5 คือค่าที่ตรวจแล้วสะอาดทั้ง 5670 combo และยังเหลือช่วงให้สไลเดอร์กว้าง

ค่าที่ถูกบังคับจะขึ้นบนสไลเดอร์เป็นสีเน้น เช่น `2.50 → 1.88` — ไม่แก้เงียบ ๆ

### ค. ตัดสไลเดอร์ Tall wall lean ออก
rake คำนวณเอง: **`rake = 0.443 × ความสูงผนังสูง`** (จากไฟล์: ตีน x 124 → เข่า x 252 = 128 บนผนังสูง 289)
guard เดิมยังทำงาน `rake ≤ crownX − 1.5` กัน eave ไปเบียดยอด · Rib Profile เหลือ 6 สไลเดอร์

เดิม 2 จุด (ตีน + ยอด) ทำให้แกน wall **ค้างที่ ~37° ไม่ว่า rake เท่าไหร่** — ที่ rake 0 ต่างกัน 37.4°
