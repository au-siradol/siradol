ตรวจหน้า "วันนี้" บน iPhone หลายขนาด

ขนาดเป็นหน่วย CSS pt ตามที่ Safari เห็นจริง · ทุกจอโหลดหน้าเดียวกัน (index.html) · เลื่อนและแตะในแต่ละจอได้

ใกล้เคียงของจริง ไม่ใช่ตัวจำลองของ Apple: ฟอนต์ Sukhumvit Set / Helvetica Neue จะแสดงถูกต้องเฉพาะเมื่อเปิดหน้านี้บน Mac หรือ iPhone · ขอบมน แถบสถานะ และแถบ Safari วาดขึ้นตามขนาดโดยประมาณ (Safari แถบล่าง ~ 83 pt) · ถ้าต้องการดูแบบตรงที่สุด ให้เปิดเว็บบน iPhone จริง หรือใช้ Safari → Develop → Responsive Design Mode บน Mac
